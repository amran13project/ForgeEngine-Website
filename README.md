# ForgeEngine Website

Official website source for ForgeEngine.

## Preview locally
Open `index.html` in a browser, or run `python -m http.server 8000` in this directory and visit `http://localhost:8000`.

## Enable GitHub Pages
1. Open repository **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose `main` and `/ (root)`, then Save.
4. GitHub Pages will display the published URL after deployment.

## Accuracy note
Some page artwork is illustrative. The terminal-style panel is a static visual preview, not a live engine terminal. Feature availability, platform support, version numbers, release dates, and downloads must always match verified engine releases. Update website copy before publishing whenever project status changes.
